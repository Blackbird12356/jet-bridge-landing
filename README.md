# Jet Bridge

Лендинг авиа-доставки из ОАЭ в Казахстан. Чистый стек без фреймворков: HTML5, CSS3, JavaScript и jQuery.

**Демо:** [jetbridge.vercel.app](https://jetbridge.vercel.app)

## Запуск

Откройте `index.html` в браузере или из папки проекта:

```bash
npx serve .
```

## Что внутри

- Одностраничный лендинг по макету Figma
- Адаптив от телефона до широкого монитора
- RU / KZ
- Анимации появления и hover
- Форма заявки с проверкой полей
